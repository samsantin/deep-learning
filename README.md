# Deep Learning — Implementations in Python

This repository contains the notebooks developed for the **Deep Learning** course.  
It includes implementations of neural networks, autoencoders, generative models, and deep learning applications using datasets such as MNIST, CIFAR-10, and others.

Each topic is implemented in a separate Jupyter Notebook (`.ipynb`).

---

## Contents

* `2_deep_mnist.ipynb` — Deep neural network applied to the MNIST dataset  
* `deep_mnist.ipynb` — Neural network models for handwritten digit classification  
* `MNIST_V2_ref.ipynb` — Alternative MNIST implementation and experimentation  
* `neural_network_scikitlearn.ipynb` — Neural networks using Scikit-learn  

### Autoencoders

* `AE_CIFAR10.ipynb` — Autoencoder implementation on the CIFAR-10 dataset  
* `Autoencoder_Cipharq10.ipynb` — Autoencoder experiments with image reconstruction  
* `DAE-Model.ipynb` — Denoising Autoencoder model  
* `DAE_Clothes_Mod.ipynb` — Denoising autoencoder applied to clothing image datasets  
* `denoising_autoencoder_classification.ipynb` — Classification using denoising autoencoders  
* `PCA_vs_AE.ipynb` — Comparison between PCA and Autoencoders for dimensionality reduction  

### Generative Models

* `gan_vs_wgan.ipynb` — Comparison between GAN and Wasserstein GAN (WGAN)  
* `pokemon_name_generator.ipynb` — Text generation model for Pokémon names  

### Reinforcement Learning / Other Applications

* `agent_from_scratch.ipynb` — Basic intelligent agent implemented from scratch  

---

## Objective

Explore deep learning architectures and techniques for classification, dimensionality reduction, generative modeling, and representation learning.
